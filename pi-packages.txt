# Pre-installed Pi Packages for the Makers deployment.
# One package source per line, same format as `pi install` / Settings → Pi packages:
#   npm:@scope/name@version    (or npm:name)
#   git:github.com/user/repo[@ref]   (NOTE: git is unavailable in the Makers sandbox)
# Lines starting with # and blank lines are ignored.
#
# IMPORTANT — /tmp budget: the Makers sandbox /tmp is a small TMPFS (~512 MB-ish).
# A full extension set (~550 MB of node_modules for 8 packages) triggers ENOSPC
# on first boot. Keep this list short; install the rest from the UI's
# Settings → Pi packages later (each still consumes sandbox /tmp, so budget it).
#
# How it works:
#   - `npm run prepare:packages` installs these at build time into vendor/pi-packages/
#     (offline at runtime; only useful for self-hosted deployments of this tree,
#     since Makers does not ship vendor/ into the sandbox).
#   - The sidecar seeds `settings.json` with these sources on boot; the matching
#     code is re-installed online by `_packages.ts` on cold start (npm cache is
#     shared at /tmp/npm-cache to keep the space cost low).
